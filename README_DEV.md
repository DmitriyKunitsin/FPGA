## 🔄 Always-блоки (3 основных шаблона)

## 1. `always_comb` — Комбинационная логика (без памяти)

**Что делает:**
Мгновенно реагирует на изменения входов. Нет задержки, нет памяти. Вход изменился → выход изменился.

**Аналогия из жизни:**
Штамповочный пресс. Кинули заготовку → получили деталь. Убрали заготовку → деталь исчезла. Ничего не хранит.

**В железе:**
LUT (комбинационная логика). Просто таблица истинности.

**Когда использовать:**

- Мультиплексоры (`if (sel) y = a; else y = b;`)
- Дешифраторы
- Простые вычисления (сложение, сравнение)
- Логика "И/ИЛИ/НЕ"

**Пример(_SystemVerilog_):**

```systemverilog
always_comb begin
    if (sel)
        y = a;     // Если sel=1, y = a
    else
        y = b;     // Если sel=0, y = b
end
```

**Важно:** В always_comb каждая переменная должна получить значение при всех условиях! Если забудете else — получите защелку (ошибка синтеза)

## 2. `always_ff` — Регистровая логика (с памятью)

**Что делает:**
Реагирует только на фронт тактового сигнала. Запоминает значение между тактами.

**Аналогия из жизни:**
Охранник на проходной. Каждый час (по звонку) записывает в журнал, кто зашел. Между записями журнал просто лежит и хранит информацию.

**В железе:**
Триггеры (Flip-Flops) — регистры, хранящие бит.

**Когда использовать:**

- Счетчики
- Регистры для хранения данных между тактами
- Конечные автоматы (состояния)
- Всё, что должно "помнить" значение от такта к такту

**Пример:**

```systemverilog

always_ff @(posedge clk or posedge reset) begin
    if (reset)
        counter <= 0;          // Асинхронный сброс
    else
        counter <= counter + 1; // По фронту clk
end
```

**Важно:**

- Используйте <= (неблокирующее присваивание) в always_ff
- Список чувствительности: только @(posedge clk) или @(posedge clk or posedge reset)
- Избегайте сложной логики внутри — выносите в always_comb

## 3. always_latch — Защелка (почти не используем)

**Что делает:**
Пока enable=1 — прозрачный (пропускает сигнал). При enable=0 — запоминает последнее значение.

**Аналогия из жизни:**
Дверь с доводчиком. Пока держите ручку (enable=1) — дверь открыта. Отпустили ручку (enable=0) — дверь закрылась и зафиксировалась.

**В железе:**
Latch (защелка). "Недо-триггер", без тактового сигнала.

**Когда использовать:**
❌ ПРАКТИЧЕСКИ НИКОГДА в FPGA/ASIC. Это обычно ошибка, которую получают, забывая else в always_comb. Защелки запрещены в серьезных проектах (чувствительны к помехам, проблемы с STA).

**Пример (как НЕ надо делать):**

```systemverilog

always_latch begin
    if (enable)
        y = a;     // НЕТ ELSE! Это защелка!
end
```

## Присваивания Блокирующие и Неблокирующие

#### Существуют разные синтактически присвания

- **Блокирующий** "=" :

  ```
    y = a + b;
  ```

  - Выполняется **последовательно** (строка за строкой), прям как в C/C++.
  - Новое значение переменной **мгновенно** и сразу доступно на **следующей** строчке кода.

- **Неблокирующий** "<=" :

  ```
    y <= a + b;
  ```

  - Выполняется паралельно
  - Сначала вычисляются **правые части** всех выражений в **блоке**, используя **старые** значения сигналов.
  - **Левые части** неблокирующих присваиваний обновляются одновременно **после** вычисления всех правых частей (**end блока always**), но до того, как начнётся следующий такт.

  ```
  always_ff @(posedge clk) begin
  if (reset) begin
    a <= 0;           // запомнили
    if (some_cond) begin
      b <= a + 1;     // запомнили (читает СТАРОЕ a)
      c <= b + 2;     // запомнили (читает СТАРОЕ b)
    end
  end
  d <= c;             // запомнили (читает СТАРОЕ c)
  end
  // <<< ВОТ ЗДЕСЬ происходит одновременное обновление a,b,c,d
  ```

**Важно:**

- При **блокирующем** порядок важен , а при **неблокирующем** - нет.

**Простые правила использования присвоений :**

- always_comb - Только **блокирующее** присвоение
- always_ff - **Неблокирующий** присвоения
- **Неблокирующие** , когда нужно синхронизировать данные с фронтами тактового сигнала
- **Блокирующие** , когда требуются временные переменные

### **Не присваивать один и тот же сигнал через = и <= в одном блоке. Для временных переменных можно использовать = в always_ff.**
