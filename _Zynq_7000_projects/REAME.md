# 📚 Учебный репозиторий по **Платой разработки ПЛИС Xilinx ZYNQ7000** чип : Zynq-7020

> **Важно:** Данный репозиторий содержит **учебные проекты**, созданные в процессе изучения FPGA-разработки на базе Zynq-7020. Исходные материалы взяты из открытых китайских архивов и адаптированы под мою плату. Это **не мои собственные проекты**, а **лабораторные работы**, которые я выполняю для освоения инструментов Vivado, Vitis, HLS, PetaLinux и PYNQ.

---

## 🎯 Цель репозитория

Систематизировать и сохранить все учебные проекты, чтобы:

- Иметь структурированную базу для повторения материала
- Отслеживать прогресс обучения (от простого к сложному)
- Быстро находить нужный пример при разработке собственных проектов
- Делиться опытом с другими начинающими разработчиками

---

## 📖 Что здесь происходит?

Это **мой личный учебный трек**. Каждый проект — это:

1. Разбор готового примера из архива
2. Перенос в структурированную папку
3. Запуск, отладка, прошивка в плату
4. Осмысление и комментирование кода
5. Фиксация результата в Git

---

### Инструменты: Vitis / SDK, язык: C/C++

- Программируем два ядра Cortex-A9 (Processing System). Настраиваем общение PS ↔ PL через шину AXI.
  | # | Проект | Что изучаем |
  |:-:|--------|-------------|
  | 01 | `01_uart_hello_world` | 🟢 Hello World — базовый вывод через UART |
  | 02 | `02_mio_gpio` | 🟢 MIO как GPIO — встроенные пины PS |
  | 03 | `03_axi_gpio` | 🟡 AXI GPIO — управление PL-пинами из PS |
  | 04 | `04_axi_gpio_interrupt` | 🟡 AXI GPIO + прерывания — обработка событий |
  | 05 | `05_freertos_multitask` | 🟡 FreeRTOS — многозадачность, задачи и очереди |
  | 06 | `06_sdcard_fatfs` | 🟡 SD-карта + FATFS — файловая система |
  | 07 | `07_uart_echo` | 🟡 UART-эхо — приём/передача с буферизацией |
  | 08 | `08_amp_dualcore` | 🟠 Два ядра AMP — асимметричная многозадачность |
  | 09 | `09_qspi_flash` | 🟠 QSPI Flash — чтение/запись внешней памяти |
  | 10 | `10_timer_interrupt` | 🟡 Таймеры — аппаратные таймеры и прерывания |
  | 11 | `11_ps_xadc` | 🟠 XADC — встроенный АЦП (температура, напряжение) |
  | 12 | `12_emmc_fatfs` | 🟠 eMMC + FATFS — встроенная flash-память |
  | 13 | `13_lwip_echo` | 🔴 TCP/IP (lwIP) — сетевой стек, эхо-сервер |
  | 14 | `14_tcp_flash_update` | 🔴 Обновление по TCP — прошивка платы по сети |
